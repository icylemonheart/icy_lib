# icy_lib

A core library mod for Minecraft NeoForge 1.21.1 providing attributes, damage types, defense pipeline, growth, quality and fancy-text UI systems for the icy series mods.

The mod source and full documentation live in the [icy_lib/](./icy_lib) subdirectory. See [icy_lib/README.md](./icy_lib/README.md) for a detailed Chinese introduction.
